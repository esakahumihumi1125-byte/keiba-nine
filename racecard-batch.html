全レース一括チェック

出馬表と評価データを最大120レースまとめて検証するための端末内の準備ツールです。JRA/JRDBの自動取得、公式照合、AIによる根拠の作成、予想の公開や購入はしません。

① データを読み込む

利用条件を確認したデータのみ使用してください。JSONを貼り付けるか、iPhoneの「ファイル」から選択できます。ファイル内容をGitHubなどへ送信・保存しません。

未検証

② 別データと出馬表を照合（任意）

別に用意した出馬表JSONと馬番・馬名・出走取消を比較します。不一致の場合はプレビューの保存と本体への引き継ぎを停止。照合用データを入れなければ、従来どおり未照合の検証用プレビューとして利用できます。

未照合：照合用JSONは入力されていません。

別ファイルの一致チェックは、JRA公式の真正性や情報の最新性の証明にはなりません。
照合用JSONの書式
{
 "kind":"keiba-nine-racecard-reference",
 "schema":1,
 "source":"別途確認した出馬表の出典",
 "checkedAt":"2026-11-06T17:30:00+09:00",
 "races":[{
   "date":"2026-11-07","track":"京都","race":1,
   "complete":true,"off":"10:00",
   "horses":[{"number":1,"name":"入力例の馬名","scratched":false}]
 }]
}

これは書式例です。実在の馬ではありません。全出走馬の番号・馬名・取消状況が必要です。

③ 開催日とレースを選ぶ

結果を端末内だけでメインアプリへ渡します。すべて検証用の暫定・見送りとして扱い、購入や正式な予想・収支には反映しません。 本体で内容を再検査し、本人が保存を選ぶまで登録されません。 JSON保存も検証用データだけを書き出し、元の根拠メモ全文や実戦記録は含めません。 日付・競馬場を選んでいる場合は、表示中のレースだけを書き出します。

まだレースデータはありません。

読み込み後に日付と競馬場ごとのレース一覧が表示されます。

④ 暫定評価・参考フォーメーション

対象レースを選ぶと結果が表示されます。

評価は入力に含まれるS/A/B/Cと根拠メモを固定加重で計算したものです。現実の勝率・回収率・馬券の購入推奨ではありません。調教や近走が不明な場合は見送りにします。

一括JSONの形式を見る 
{
  "kind": "keiba-nine-racecards",
  "schema": 1,
  "source": "利用許諾を確認した提供元",
  "licenseConfirmed": true,
  "racecards": [
    {
      "date": "YYYY-MM-DD",
      "track": "京都",
      "race": 1,
      "horses": [
        {
          "number": 1,
          "name": "公式情報から転記した馬名",
          "scratched": false,
          "evaluations": {
            "recent": {"grade":"A","note":"近走内容の具体的な根拠"},
            "training": {"grade":"B","note":"調教時計など具体的な根拠"},
            "course": {"grade":"A","note":"距離適性など具体的な根拠"},
            "pedigree": {"grade":"B","note":"血統適性など具体的な根拠"},
            "pace": {"grade":"B","note":"想定展開など具体的な根拠"}
          }
        }
      ]
    }
  ]
}

これは構造例であり実データではありません。各馬の評価と取消状況がすべてそろうまでは見送りとなります。提供元欄や利用許諾フラグは自己申告であり、利用権限を証明するものではありません。
