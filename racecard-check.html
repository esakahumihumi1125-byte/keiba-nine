入力形式を見る（データがそろった場合） 
{
  "source": "利用許諾を確認した提供元",
  "licenseConfirmed": true,
  "date": "YYYY-MM-DD",
  "track": "京都",
  "race": 1,
  "horses": [
    {
      "number": 1,
      "name": "公式情報から転記した馬名",
      "scratched": false,
      "evaluations": {
        "recent": {"grade": "A", "note": "前走内容・相手関係など具体的な根拠"},
        "training": {"grade": "B", "note": "調教時計や負荷など具体的な根拠"},
        "course": {"grade": "A", "note": "距離・コース実績など具体的な根拠"},
        "pedigree": {"grade": "B", "note": "血統適性など具体的な根拠"},
        "pace": {"grade": "B", "note": "先行力・展開予測など具体的な根拠"}
      }
    }
  ]
}

これは構造の説明です。実在する馬のデータや評価を示すものではありません。grade は S/A/B/C、note は8文字以上が必要です。すべての出走候補の評価がそろわなければ買い目は作りません。

重要：この画面は形式・入力の整合性のみ確認します。レースの実在、馬名・馬番、出走取消、馬場状態、データの利用許諾の真偽は検証できません。実データ自動連携には正式な提供元との接続が必要です。
