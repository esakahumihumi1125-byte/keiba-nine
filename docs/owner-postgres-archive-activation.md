# 競馬ナイン本人用：発走前研究記録のサーバー永続保存

更新日：2026-11-09

## 現在の状態と注意

本人用Render `keiba-nine-owner-jrdb` は Free Web Service で、**Render Postgresは未作成**（2026-11-09確認）。
`KEIBA_OWNER_RECEIPT_ARCHIVE_ENABLED` を有効にした、という意味ではない。

- 今ある端末内の署名付き予想は、既存の `/owner-backup` でJSONとして安全な場所にバックアップする。
- **データベースを新設しない限り、サーバーに予想記録は永続保存されない。** Render Freeのアプリ内ファイルに記録を置く方式は採用しない。
- 新設Postgresは料金・保管期間・バックアップ仕様に影響する。ユーザーの予算承認なしで作らない。
- 発走後に古い未保存の予想を、新しくサーバー保存した発走前記録として作り直してはいけない。
- 保存対象は発走前の研究用3連単の馬番・点数・サーバー署名・固定時刻のみ。JRDB有料生データ、オッズ、実購入、確定結果、パスワードは保存しない。

## 事前に実装済みの構成

- `scripts/owner_receipt_archive.py`：本人専用Postgresを使用し、race_day / track / race_noの主キーで最初の固定を維持。新しい買い目が来ても `ON CONFLICT DO NOTHING`。DB時計が発走時刻以降なら追加しない。秘密キーは本人ログイン用パスワードと分離。
- `migrations/owner_receipt_archive.sql`：テーブル作成、許可馬場・Rの制約。アプリ用DBロールにはSELECT/INSERTのみを許可し、UPDATE/DELETE/TRUNCATE/DDLを許可しない。
- `/api/jrdb/owner-auto-draft`：保存が有効な場合にだけ、署名後に保存し、再計算と衝突したレースは古い保存済みの買い目を優先して新規提案を保留する。
- `GET /api/owner-archive-read?date=YYYY-MM-DD`：**本人認証・HTTPS・追加ヘッダー必須**。本人がボタンを押した時だけ、指定日の署名を再検証して保存済み記録を読み取る。DB未設定なら安全に未設定を返し、新しいデータは保存しない。結果が未確認なら回収率に加算しない。
- 本人用 `/owner-auto-forecast` → 「発走前に固定した買い目の履歴」 → 「サーバー保存済みの記録を見る」。読み取ったデータは画面で見るだけで、端末保存を上書きしない。

## 将来、有料の永続保存を選ぶ場合の安全な有効化順

1. RenderのDB料金、利用期間、バックアップ／復元方針を本人が確認・承認する。無料/期限付きの一時DBは長期記録には使わない。
2. 本人専用の永続Postgresを作成し、`migrations/owner_receipt_archive.sql` のテーブルを**管理者として一度だけ**作る。アプリ用アカウントは別に発行し、テーブルにSELECT/INSERTのみを許可する。
3. `keiba-nine-owner-jrdb` のRender Environmentに `KEIBA_OWNER_RECEIPT_ARCHIVE_DATABASE_URL`、本人用の新しい十分に長いランダム文字列 `KEIBA_OWNER_RECEIPT_SIGNING_SECRET` を設定。どちらもチャット、スクショ、GitHubには貼らない。**既存のJRDBキーやログインパスワードを流用しない**。
4. 接続先・権限・バックアップが正常か検証できた後、**最後に** `KEIBA_OWNER_RECEIPT_ARCHIVE_ENABLED=1` を有効化する。設定不足時は安全に停止する仕様。
5. 新しい開催日の発走前に本人用アプリを開き、発走前の研究買い目を生成。初回記録が保存されることを確認し、再分析で別の買い目が来ても初回記録が残ることを点検する。
6. 別のiPhoneなどからは「サーバー保存済みの記録を見る」で閲覧可能。まだ**自動復元機能ではない**。端末バックアップは引き続き維持する。

## 停止・障害時

DB接続、署名、開催日の照合のいずれかが失敗すれば、サーバー保存が完了したと表示しない。既存レコードを後から上書きしない。Postgresのデータ消失対策は、Renderでのバックアップ設定・外部エクスポート・復旧テストを別途行う。

**署名が検証できても、JRA公式の発走時刻や出走取消、公式結果、実際の投票・払戻は証明されない。**
