# 競馬ナイン：1着候補・総合順位の取りこぼし検証（架空データ専用）

## 何を確認するか

`scripts/research_winner_diagnostics.py` は、予想時点で固定した評価と
レース後に与えた**架空の着順**を突き合わせます。

- 勝ち馬が総合1位／3位以内／4位以下／未評価のどれだったか
- 勝ち馬が「勝ち切り再検討候補」に含まれていたか
- 再検討候補にいたのに、実際の**架空3連単の1着欄**には入っていなかったか
- 3連単が的中したか（モデルが`simulate`判定した架空馬券のみ）
- 投資額・払戻・回収率（架空馬券・確定結果のみ）
- 開発用期間と未使用検証期間の差（時系列分割）

これは「勝ち馬を拾えているのに1着を逃した」「総合4〜6位から勝ち馬が
出た」という課題を**検証方法として**整理するものです。
過去の実戦成績が自動で読み込まれたり、勝率・回収率が改善したりするわけではありません。

## 安全な設計

- 入力は`recordType: test`のみ。実データ・有料JRDB・My KEIBA・即PAT・
  公開フィードへは一切接続しません。
- `research_backtest.backtest`が結果を見ずに予想スナップショットを固定。
  その**後**に結果を読み、同じ`predictionHash`で検証します。
- `hold`・`skip`となったレースについても着順の整合性を確認し、
  未評価の勝ち馬は「順位不明」と記録。無理に4位以下へ入れません。
- 中止・未確定は分母に入れず、同着・除外など未対応の着順を拒否します。
- 「検証期間20R以上」などの条件を満たしても、**架空成績は本番の妥当性を示しません**。
  `calibrated`、`approvedForLive`、`approvedForPublication`、
  `approvedForBetting` は常に false です。
- オッズ・人気を使わず、結果に合わせて閾値や配分を自動調整しません。
