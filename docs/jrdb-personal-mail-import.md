# JRDB「想定確定」メールの本人専用・端末内取り込み

- URL: ログイン済み本人用 `/jrdb-mail-local`。本人がGmail等から**1通ずつメール本文をコピーして貼り付ける**方式で、Gmail自動同期はまだありません。
- `■想定確定`、開催日・競馬場・発走予定時刻、1R〜12R、予定登録頭数と馬名の並びを解析し、`localStorage` に**開催日・競馬場・レース・時刻・予定頭数・馬名のみ**保存。メール原文、騎手名、厩舎名、提供元の権利表示などは保存しません。
- 取り込み成功後、メール本文の入力欄は自動クリア。同じ日付・競馬場は置き換え、別会場は保持。保存件数は最大16開催組み合わせ。
- メール本文が不完全で、予定頭数と抽出できた馬名数が一致しない場合は**保存しない**。重複レース、馬名重複、不正な開催日時、19頭以上、不正形式も拒否。
- HTML/JS/CSSコードだけを既存の本人認証付きRenderから配信します。メール本文と解析した実データを**サーバーへPOST/送信しません**。GitHub・公開Pages・Googleスプレッドシート・ChatGPTへの自動転送もしません。
- 既存の3連単下書きや実購入のブラウザー保存領域とは**別キー**を使用し、消去ボタンでも今回取り込んだ想定メール予定しか消去しません。
- 本人用の競馬予想に限ります。JRDBの一般公開・再配布禁止条項を遵守。サブスク・一般公開向けフィードとは絶対に接続しません。
- **馬番・枠順が未確定の「想定確定」メールから3連単は作成しない**。JRAの公式出馬表・取消・騎手・斤量・馬場・発走時刻は後で独立して最終照合します。適性・調教ランクや予想は別工程。
- メール文面の構造が変わった場合は無理に取り込まず、明確なエラーを表示します。解析の正確性は実メール全種について未検証です。

公式規約：https://jrdb.com/terms

実装・テスト：`scripts/jrdb_mail_local_import.py`、`tests/test_jrdb_mail_local_import.py`、`scripts/check-private-jrdb-mail-local.cjs`。
