# 競馬ナイン：実馬評価の前提条件チェック（本人専用・現時点は未許可）

今回のコードは **S/A/B/Cを計算する機能ではありません**。既存の
`POST /api/jrdb/history` を本人が明示的に実行した場合に限り、
すでにメモリ内にある匿名化済み10項目資料と過去履歴の不足数を
`scripts/jrdb_real_assessment_preflight.py` で確認します。
新しいJRDB通信、保存、公開フィード、実馬予想、馬券購入は発生しません。

## 判定内容

各競馬場・レースの匿名集計だけを返します。

- 利用権限・許諾の確認：未確認（キーの存在とは別問題）
- JRA公式の出走馬・取消・発走時刻・馬場の独立最終照合：未接続
- 調教・近走の独自暫定閾値やその他8項目の**能力評価基準**：未検証
- 当日の馬体重・増減と馬体状態：未取得・未評価
- 過去番組/馬場の照合不足と、同芝ダート・近距離条件の比較資料不足：件数のみ表示
- 騎手・厩舎名と馬体形状コードの記録不足：件数のみ表示

`sourceMaterialSlots: 10` は10項目が全部評価可能という意味ではなく、
単に10個の**データ整理用枠**があるという意味です。
`verifiedFactorCount: 0`、`realGradeReady: false`、
`realPredictionReady: false`、`purchaseReady: false` が現状の結果です。

新馬の近走欠如、過去比較0走、取消情報未反映などのデータ不足は、
能力が低いことやC評価を示しません。実際にCと判定するには
反証・条件・比較母集団など、別の妥当性検証が必要です。

## 安全境界

不正な日時やレース、複数レースの混合、頭数・履歴件数の矛盾、
偽の評価済みフラグがあれば停止します。非公開の馬番、馬名、
過去走の原データ、APIキーや血統・騎手の個別記録は返しません。

架空データの自動テストでしか動作を検証していません。
実データの利用許諾・専用API認証・非公開の本人専用環境が必要です。
特に公開GitHub Pagesには有料データの原本やそこから導いた
予想を置かないでください。

## 次の実装の条件

専用API認証と利用範囲、非公開の保存場所が揃った後に、
出走馬の確定・取消・馬場・発走時刻の独立照合と、過去の
未使用期間での評価・回収率の検証を進めます。
その工程をクリアするまでは、実戦用S/A/B/C、My KEIBAの
購入連携、3連単自動生成には接続しません。
