# 出走表の照合

おすすめ予想の新規保存に、同じ開催日・競馬場・Rの `raceCard` が必要です。未取得・全頭未確認は照合待ち。馬番の重複、取消・除外、候補にない馬番、登録馬名の不一致は保存を停止します。買い目を自動で補充・差し替えません。

```json
{
  "raceCard": {
    "date": "2030-01-02",
    "track": "京都",
    "race": 1,
    "complete": true,
    "source": "架空テスト資料。実運用では確認した出典を指定",
    "checkedAt": "2030-01-01T08:00:00+09:00",
    "runners": [
      {"number": 1, "name": "架空馬", "status": "active"}
    ]
  }
}
```

`complete` は提供側で全頭確認したことの宣言です。アプリが公式サイトと直接照合するものではありません。状態は `active`（出走予定）、`scratched`（取消）、`excluded`（除外）のいずれか。取消馬も元の馬番で残します。頭数は1〜18頭、馬番は1〜18の重複なし。確認日時はタイムゾーン必須で、端末時計より未来なら保存できません。

全頭一覧・出典・確認日時は予想画面で確認できます。確認後の取消変更は自動取得しません。連携先が決まるまでは既存JSON取り込み経由で受け取ります。出走表変更も予想の更新として扱い、古い画面からの保存を拒否します。過去の保存版や購入記録は変更しません。

対象はおすすめ予想の新規保存です。配信データの受信履歴・旧手入力記録・WIN5の手動確認は別の仕組みとして維持します。
