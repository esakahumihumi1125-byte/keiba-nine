# 競馬ナイン｜正式10項目採点の実装状況

2026-11-09 更新。本人専用・非公開研究用。公開や馬券の自動購入はしない。

## 重み（100点満点）

| 項目 | 配点 |
|---|---:|
| 調教 | 30 |
| 近走 | 3 |
| コース・距離 | 20 |
| 展開・脚質 | 20 |
| 馬場 | 12 |
| 血統 | 8 |
| 枠・斤量 | 3 |
| 騎手・厩舎 | 2 |
| ローテ | 1 |
| 当日馬体重 | 1 |

各項目の検証済み S/A/B/C はそれぞれ配点の 100%、2/3、1/3、0%。
厳密な3倍整数のまま全項目を加算し、最後に3で割って100点表示する。
総合ランク境界は S=85点以上、A=70点以上、B=55点以上、C=55点未満。
例えば調教A20/30点、近走C0/3点、ほかの8項目すべてS67/67点なら総合87点でS。
前走の悪い着順だけで失格にはしない。近走項目のSとCの最大差は3点。

正式採点エンジン（scripts/owner_full_ten_factor.py）には、各馬の各項目別点数内訳、
整数による得点再検算、順位・総合ランク、同点境界の見送り、独立材料による穴馬の
1着再審査候補（自動買い目変更なし）を実装している。

## エンジン完成と実レースでの本採点は違う

**計算エンジンは架空の証拠つきデータでテスト済み。実レースの正式採点はまだ未完成。**

本人用のJRDB自動予想は現在、調教と近走の「仮評価2項目」だけで下書きを作っている。
この仮評価は正式な検証済み点数ではない。ほかの8項目は、資料の有無や過去実績の
件数だけでは正式S/A/B/Cに昇格しない。新馬や記録欠損はCではなく「未評価」。

JRA公式の確定出走馬・取消・馬場・発走時刻の独立照合、全10項目の妥当性検証、
当日馬体重の取得、発走前の同一スナップショットの確認が完了するまでは
総合100点の実戦ランクや正式3連単を出さない。
JRA公式PDFのリンクを見つけただけでは独立照合ではない。

## 安全ゲート

- 1項目でも未評価なら、全体の順位・買い目は作成しない。
- 馬番の重複、発走後の更新、未来の証拠、候補境界の同点は見送り。
- JRA公式照合4項目のうち1つでも未確認なら正式3連単は0点。
- 取消や出走に未解決の疑義が1頭でもあれば、10項目がそろっていても3連単は0点。
- 85点ちょうどはS、84.67点はA。表示丸めによりSに昇格しない。
- 近走がCでも調教A・ほか8項目Sなら総合Sになる。
- 実馬の公式未照合の暫定3連単や発走前固定済み履歴は、今回のエンジン更新で変更しない。

## 今回追加：調教・コース距離・展開の3本柱（研究用70点）

既存の本人用追加履歴ルート（POST /api/jrdb/history）から、当日の調教仮評価、
過去の同条件での好走歴、過去4角の位置に基づく展開仮説を**同じ馬番**で結合する。
新しいJRDB呼び出しは増やさず、既存の必要時のみの履歴照合（最大8過去レース、
最大16の追加履歴API照合）の中で計算する。

- 配点は調教30点＋コース・距離20点＋展開・脚質20点＝合計70点。
- S/A/B/C の仮の帯を配点×3/3、2/3、1/3、0で換算する。**これは未検証の70点比較値**であり、100点中の70点を獲得したという意味ではない。
- 3つのうち1つでも帯が「未評価」なら、その馬の研究用70点も「未評価」。不足項目をCや0点で補完しない。
- 現行の研究用帯は距離の過去3着内率と過去4角の情報を利用する。今走の適性や展開の予測精度は未検証なので、**正式採点0/10**を維持。
- 研究用70点に順位、馬券、正式ランクを付けない。すでに端末に固定した調教・近走2項目版の買い目や収支も変更しない。
- 公開ページではなく、本人用の「過去の同条件を最大8件照合する」を押した後に限り、各レースの「重点3項目の研究用70点を見る」に表示する。履歴連携が無効・不足時は表示できない。
- APIキー、馬名、JRDBの有料生データ、個別指数はレスポンスとGitHubに出さない。
