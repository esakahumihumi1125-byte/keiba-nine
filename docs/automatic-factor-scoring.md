## 研究段階の5項目・配点最大57点分

1. **距離適性17点**：`distance_aptitude_cd1` と芝/ダート距離帯の
   独自仮説。一致85、隣接65、離れた帯40、万能75。
   **競馬場コース別実績や左右の適性は未評価。**
2. **馬場12点（追加）**：`/tka` の芝/ダート別馬場が「稍重」「重」
   「不良」であり、対応レースと照合でき、`/tky` の `mudder_cd`
   が JRDB公式の 1（得意）・2（普通）・3（苦手）のときだけ評価。
   暫定0〜100仮説は稍重：1→80、2→65、3→45、
   重・不良：1→90、2→70、3→35。
   **良馬場は重適性コードで評価しない。** 馬場情報未提供・欠損・
   対象不明・障害は未評価（0点にしない）。
   **JRDBの独自馬場状態であり、JRA公式照合ではない。**
   更新時刻の新しさも保証せず、能力・勝率ではない。
3. **展開・脚質17点**：全頭の脚質から前方型比率を推測した仮説。
4. **騎手・厩舎10点**：全頭の各指数をレース内の順位百分位に換算。
5. **ローテ1点**：前走14〜56日80、それ以外の7〜90日65、その他50。
   前走日不明・新馬は未評価。

寄与点=仮の0〜100点×配点/100。S/A/B/Cの暫定境界は85/70/55。
未評価は0点に補完しない。**調教30点・近走3点と尺度未校正なので、
総合100点には足さず、買い目へ反映しない。**
人気・オッズは参照しない。発走後・出走頭数不一致・取消状態不明は保留する。
