# 本人用：取得済みデータからの追加自動採点

2026-11-16。`owner_automatic_factor_scores.py` を既存の
`/api/jrdb/owner-auto-draft` に接続した。追加取得は0回。
展開17、騎手厩舎10、ローテ1の最大28点分を馬別10項目欄へ表示する。
調教・近走の資料が不足したRでも、この3項目の資料があれば点数を確認できる。

## ルール v1（精度検証前）

- 展開：全出走馬の脚質が判明している場合に限る。逃げ・先行の割合が
  50%以上なら速い展開、25%以下なら遅い展開、その他は中間と仮定する。
  各脚質への得点はコード内の明示表を使う。実際のペース予測を保証しない。
  コード5（好位差し）、6（自在）も認識する。
- 騎手厩舎：全出走馬の騎手指数と厩舎指数の各中間順位百分位を等分する。
  指数の単位差をそのまま合算しない。同値は同点、全頭同値は50点。
  両方の指数が全頭分なければこの項目は未評価。能力の絶対評価ではない。
- ローテ：前走日から14〜56日は80、その他7〜90日は65、それ以外は50。
  これは暫定仮説で、休養明け得手不得手や個体差をまだ学習していない。
  初出走・前走日欠損は未評価。前走日の未来混入と馬の取り違えは拒否する。

各0〜100の値×配点/100で寄与点を求め、小数4桁で保持、画面は小数2桁。
S/A/B/Cは85/70/55境界。新しい連続値モデルと旧調教・近走の順序尺度は
校正済みの同一尺度ではなく、総合点へ合算しない。

出走頭数不一致、取消状態不明、4頭未満、発走時刻不明、発走後は採点しない。
取消済みの馬は相対比較から除外。人気・オッズ・総合印は参照しない。
本人認証済み応答には馬番・派生点・固定の理由コードだけを追加する。

## 完成していない箇所

枠斤量、馬体重の自動採点、JRA独立照合、本番の実データ検証が残る。
既存の2項目買い目・署名・初回固定保存・収支は変更しない。
画面に新点数が出ても、それが買い目に反映されていると説明しないこと。
