# 競馬ナイン本人用：2026年11月14日（土）利用チェック

**目標**：土曜朝にiPhoneで `/owner-auto-forecast` を開き、JRDB β実データから当日の**研究用暫定予想**を確認し、発走前の3連単下書きを保存・バックアップできること。

## 1. 土曜日の最短操作（本人用iPhone）

1. [本人用の予想画面](https://keiba-nine-owner-jrdb.onrender.com/owner-auto-forecast) をSafariで開き、ログインする。**日付が2026-11-14になっているか**確認。当日ページを開けば一度自動取得する。もし手動で過去の日を選択している場合、開催日を変更して「全場・全Rを再分析する」を押す。
2. ページ先頭の「開催日の利用状況」を確認する。「番組N R／発走前の研究用3連単下書きX R／見送りY R」の数と、端末固定・保存状態を見る。開催場やレース数は**実際の配信内容に従う**。36Rを決め打ちしない。0R、見送りばかり、エラーの場合は無理に予想を作らない。
3. 「開催日のレース一覧に進む」から「下書きのみ」へ。見たいレースを選択し、1着／2着／3着の馬番・重複除外した点数・100円換算を確認する。最大40点の研究用買い目で、全レース必ず30〜40点になるという保証はない。
4. 「発走前に固定した買い目の履歴」でその日の記録があるか確認する。「この日の固定買い目をサーバーで署名確認」は**保存済み署名の検証だけ**。サーバー上に保存された証明ではない。
5. 必要に応じて「8種類の記録をバックアップ・復元する」で端末記録をバックアップする。Safariとホーム画面アプリで端末保存領域が異なる場合があるので、同じブラウザー／画面を使う。
6. 実際の購入前には**JRA公式の出走馬、取消、馬場、発走時刻**を本人が別途確認する。アプリは投票・購入を自動実行しない。

## 3. 土曜当日の停止条件

- 「番組0R」「通信失敗」「資料不足」「見送り」なら、過去の保存済みレースから**後付けで買い目を生成しない**。
- 同点境界、馬番と資料の不一致、取消情報の未確認などがあれば、暫定案が出ない場合がある。
- すでに発走したレースの固定記録は、過去の結果を見てから新規追加・差し替えしない。
- 署名確認やデータベースの読み取りが失敗しても、**iPhoneの既存記録は削除しない**。
- JRDB βの生データ、個人の認証キー、秘密URL、馬名や指数の有料詳細はGitHubやチャットには共有しない。
