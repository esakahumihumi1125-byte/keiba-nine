# 馬別資料の登録状況チェック

`python scripts/data_readiness.py keiba-nine-auto-feed.json`

配信JSONの全頭出走表を基準に、出走予定馬ごとの馬名照合・近走・調教の不足を標準出力へ表示します。評価した馬だけを対象にして未評価馬を見落とさないための開発用コマンドです。アプリ画面への追加ではありません。

開催日より前の日付・出典・内容がある記録のみ数えます。当日記録は時刻を確認できないため対象外。新馬など近走がない場合も不足として表示し、架空記録で埋めません。取消・除外は集計外です。

登録件数は資料の品質・真偽・鮮度を保証しません。全項目が揃っても購入推奨や公開許可にはなりません。元JSON、公開予想、利用者の記録を変更せず、通信・有料API呼び出しもありません。データ提供元への実接続は別途必要です。
