# 公式結果を使うブラウザ動作検証

2026-10-29にJRA公式の2025-06-01東京11R日本ダービー結果を確認。
出典: https://www.jra.go.jp/datafile/seiseki/g1/derby/result/derby2025.html
上位3頭の馬番、100円あたりの3連単・3連複配当、開催日時だけを検証用に保持する。

```sh
npm install --prefix /tmp/keiba-ui-check jsdom --no-audit --no-fund
NODE_PATH=/tmp/keiba-ui-check/node_modules node tests/real-result-flow.cjs
```

本番HTMLを独立したブラウザ保存領域で起動し、バックアップ入力→結果フォーム入力→保存→再読み込み→期間選択を確認する。ネットワークの配信取得は空データで置き換え、ユーザーの保存領域やGoogleへは接続しない。

2点の買い目は結果を見た後で検算用に作成しており、予想ではない。保存日時を現在時刻にして、発走前の記録として扱われないことを確認する。正しい着順での払戻計算、2・3着逆転時の不的中、実購入登録の拒否、仮想・実購入収支への非算入を検証する。

これは予想精度・回収率の検証ではない。出走前の全頭データ・調教・近走による予想生成や実端末Safariでの操作は未検証。公式結果ページをレース前の出走表に流用しない。継続的な自動収集の仕組みやデータ提供契約も追加していない。
