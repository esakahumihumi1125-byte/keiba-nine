# 予想データと馬別根拠の表示

評価ランクと買い目候補の和集合を対象に、馬名・過去成績・調教記録の登録頭数を表示する。全出走馬の取得完了、資料の真偽、最新性を保証する表示ではない。評価やコメントだけでは実記録取得済みに数えない。

既存の `horses[].reason` を優先し、なければ `strength` を48文字まで表示する。全文と `risk` は開いて確認できる。どちらもなければ「根拠未登録」。ランクから理由を推測したり、未取得項目を補完したりしない。

各馬に以下の任意項目を追加できる。未指定なら空配列。1項目20件以内、各記録は実在する日付・空でない出典・具体的な内容が必要。既存の配信JSON/手動取り込みを通す。自動データ提供元への接続は別途必要。

```json
{
  "number": 1,
  "name": "架空テスト馬",
  "overall": "S",
  "reason": "テスト用の評価理由。実際の予想ではありません。",
  "risk": "テスト用の注意点",
  "recentRuns": [
    {"date": "2026-10-20", "source": "架空テスト資料", "detail": "架空の過去成績。実成績ではありません。"}
  ],
  "workouts": [
    {"date": "2026-10-22", "source": "架空テスト資料", "detail": "架空の調教記録。実記録ではありません。"}
  ]
}
```

出典メモと確認日時は既存の `evidence.references` と `evidence.checkedAt` を表示する。記録は正規化後も保持し、保存した予想スナップショットに含める。過去の保存版の上書きはしない。
